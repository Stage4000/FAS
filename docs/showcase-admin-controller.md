# Dormant private moderation composition

`ShowcaseAdminController` composes the private queue, review, photo and moderation response flows. It does not start a session, expose a route, provision storage, publish any photo or issue an incentive. Current FAS admin integration must supply the existing locked native admin session, current server-side CSRF, `ShowcaseAdminAuthorization::actor` callback, strict enable callback and fixed same-origin `/admin/` route paths.

The request boundary and controller must receive the same repository and current authorization policy. Repository authorization rechecks every private operation and the write transaction, rather than trusting initial actor resolution alone. A revoked session before dispatch yields 403. Revocation detected deeper in repository operations yields generic 503 without leaking the private row or cause. Strictly disabled composition never resolves an actor or touches the repository.

GET queue defaults to 20 and uses the repository's keyset cursor contract; arbitrary limits, array parameters and partial cursors are rejected. Detail serves escaped private data with CSRF-bound decisions. Private JPEG response uses only verified regenerated bytes. GET cannot mutate. POST requires the existing request validator's CSRF and exact review snapshot. Successful decisions redirect 303 to the fixed review URL; duplicate/stale decisions return 409 without another audit write. Responses, including errors, are no-store and nosniff. The route dispatcher must emit returned headers and persist the native session before output.

Deployment still requires actual admin route/session/theme wiring, full host/browser acceptance, consent/privacy/incentive choices, production provisioning and existing source-publication approval. This candidate neither resolves nor bypasses those gates. Local tests use synthetic records only.

## Native HTTP integration coverage (November 14)

The isolated native HTTP harness composes this controller with the exact pinned FAS `AdminAuth` class (Git blob `f387c7c6657d247e0709951b17f5da45f160aa74`), native PHP file sessions/cookies, current authorization bridge and real SQLite showcase repository. Account lookup/token dependencies are synthetic, and the `AdminAuth` constructor is bypassed to avoid unrelated schema setup. Tests exercise queue/detail/private image access, escaping, cross-session and wrong CSRF, POST redirects, repeat/stale decisions, withdrawal, logout, and current account deletion, role downgrade, token revocation and disabled-account rejection.

The fixture login/logout endpoints and header gates exist only in a CLI-server test router and must never be deployed. The account file is private within a temporary tree. This is plain loopback HTTP, not browser, TLS, production account storage, live CSRF/bootstrap integration, or release acceptance. All 44 checks passed on Linux PHP 8.4.24.
