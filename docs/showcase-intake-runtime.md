# Dormant private intake factory

ShowcaseIntakeRuntime composes existing private repository/quota files and host slot leases into the intake application. The root entry loads the module before evaluating its private bootstrap. No bootstrap/config file is shipped, no database/slot is created, and no intake is enabled. Existing host/bootstrap/privacy/retention/incentive and release gates remain.

A trusted bootstrap returns `ShowcaseIntakeRuntime::compose(config, enabled, identity, clock, capacityGate)`. The exact 15 keys are enforced; all values must be explicitly chosen by deployment, not derived from client fields. The route is fixed to `/showcase.php`. Consent text/version and quota/secret/store budgets require reviewed values. Both enable checks are literal-true. Denied initial enablement avoids all config/storage work. Composition opens and validates existing stores but does not resolve identity, call clock, charge quota or lease a slot. Opened repository permanently denies moderation. No admin authorization is granted to intake.

The factory is invoked before the root starts its secure dedicated session. Only `handle` runs with the active exclusive session lock; identity resolution must defer until then and must use a trusted stable server identity. A rotating session ID alone does not establish a robust per-person limit. Global quota, server decoder/process memory/time budgets and identical immutable private slot files across workers remain required. Slot paths are validated by the existing concurrency implementation when POST executes, not by GET or composition. `capacityGate` is independent strict capacity admission, never a second quota charge. No reverse-proxy/TLS trust changes are provided.

Configuration bounds use existing underlying implementations. Slot/database parent ownership, hardlink/replacement prevention, physical disk quotas and actual production TLS/browser acceptance are still deployment responsibilities. Include/construct never starts sessions, outputs, publishes photos, issues coupons or sends email.
