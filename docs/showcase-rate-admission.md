# Mandatory quota candidate (not production enabled)

`ShowcaseRateAdmission` requires an existing canonical private POSIX SQLite file outside every explicitly configured public root. It opens READWRITE without CREATE. Schema/configuration provisioning is separate: create exactly the public SCHEMA and STATE_SCHEMA constants and one state row `(1, binding(secret, actorLimit, windowSeconds, capacity, globalLimit), 0, 0, 0)`. Do not initialize on an HTTP request. Secret must be stable, cryptographically random and server-held; minimum length validation does not establish entropy.

`admit(trustedActorIdentity)` atomically charges one attempt against both actor and host-global windows or throws. Use as the strict gate inside ShowcaseConcurrency so its lease remains held through quota charging and decoding/storage. Failed upload attempts remain charged. Actor identifiers must be resolved by trusted controller code, not arbitrary request-supplied keys. HMAC pseudonyms, integer times and counters only are persisted, never raw identity/content. Pseudonyms still constitute potentially linkable operational data, not anonymous data.

Fixed windows begin at first use, expire exactly at start+window, and may allow boundary bursts. Global quota protects against arbitrary unique identities. At actor capacity, new actors fail closed without evicting active records; expired rows are pruned in the same transaction. Transaction failure or denial rolls back all accounting. All workers must use identical config and secret; mismatch refuses opening. Changing policy/key requires explicitly planned reprovisioning and affects retained quotas, not silent runtime reset.

Clock must be trusted integer seconds. Values earlier than last committed admission, any actor start, or global start fail closed. SQLite busy failures also deny. This is one host/database, not distributed service. Protect database, sidecars and all directories from hostile writes, symlink replacement and hardlinks; path checks are not an ACL audit. Schema SQL is exact and additional tables/triggers/views are refused. No live DB used.
